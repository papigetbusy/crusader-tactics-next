# The Codex

- `old-codex-v0.22.html`: the old game's Codex (v0.21/0.22), uploaded unchanged as an archive. It is older than the old game's last animations, so it is not the authority for how attacks look.
- The new Codex is published with the game (`codex.html`) and is built from the game's own data files by `tools/codex`, so it always matches the code.
- `../codex-checklist.md`: every entry of the old Codex, and where it is in the new game (same, changed, or removed, with the reason).
