# Sprite prompt

Paste the block. Change only the FILL lines. Do not add extra instructions.

The body row is always the same person, full body, no spell.
The effect row is always the spell only, no person.
Say who it is, and name the other forms that must not appear.

```
Sprite sheet for FILL SKILL. One character only: FILL WHO.
Copy that character from the attached image. Same face, hat, clothes, weapon, colors, and size in every frame.
Do not draw FILL NOT.
Flat background #FF00FF. Do not write a color code on the sheet. No floor, no scenery, no enemy.

Two rows. Eight equal cells. Label under each picture, exact text, not touching the picture.

Row 1, the character only. Full body in every cell. No spell. No second character.
FILL BODY 1 — idle.
FILL BODY 2 — the start of the move.
FILL BODY 3 — the windup.
FILL BODY 4 — reaching into the move.
FILL BODY 5 — the move, held.
FILL BODY 6 — the same move, still held. The character is still fully visible.
FILL BODY 7 — coming back to idle.
FILL BODY 8 — exact copy of body 1.

Row 2, the spell only. No character.
FILL EFFECT 1 through EFFECT 8. One step of the spell each. Same colors as the skill. No other skill's effect.
```
