# Attack code, held back on purpose

Nothing in this folder is wired into the game.

Rules:

- One file per attack, and only after the owner signs off one GIF for it.
- The file is named after the attack, not after a version. `blood-moon.js` is the one. There is no `blood-moon-v1.js`.
- The file only describes how the screen plays the pictures (which frames, how long, where the hit lands). It does not change hit chance, damage or any other rule.
- These files get copied into the game once, when every row of `../CHECKLIST.md` is signed off. Not one at a time.
